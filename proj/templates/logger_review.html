Instructions

  • Choose a Submission ID, then check parameters in the Parameter dropdown. Selected parameters overlap on one time plot. Each colored line has a matching independent raw-unit y axis.
  • Drag to zoom. Double-click restores the plot. All four QC tests are shown together. Circles mark suspect readings and crosses mark failed readings, colored by test.
  • Check a parameter under Show tests for to show its test markers and its editable threshold table. All test limits are editable in the table. Values use the selected parameter units, except SD and repeat counts where labeled. Changing a limit updates all plotted flags immediately. Reset thresholds restores the calibration defaults from thresholds_main.yaml.
  • Review notes, periods, thresholds and status are saved for each submission as you work. Finalize writes the submission to the final data table. Finalize but need another QA holds it until a different reviewer finalizes. Reject submission keeps it out of the final table.
  • Editing a finalized, rejected or needs another QA review returns it to Draft and removes its rows from the final table.
